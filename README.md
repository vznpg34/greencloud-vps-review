## 退款政策先看清楚：月付和特价年付是两套规则

这是多数测评文章不会展开讲、但直接影响你钱包的部分。绿云的退款分两种情况：

1. **常规套餐**：新客户的第一台 VPS，购买后 7 天内可申请退款。仅限新客户，老客户续费不适用。
2. **特价/折扣套餐**：官方页面明确标注不提供退款或退款保障，包括 Budget Sale 这类年付促销款。加密货币（比特币等）支付一律不退。

所以下单前先问自己一个问题：这台机器万一不满意，我能不能接受钱拿不回来？能接受，年付特价款的性价比确实高（月均一两美元）；不能接受，就选月付款，7 天内随时止损，最多损失一个月的钱。

续费价格还有一层不确定性：第三方比价平台核验时发现，绿云多数套餐的续费价在结账前标注为“未确认”，而社区里也确实有过续费对老用户不友好的抱怨。这条和“特价款不退款”叠在一起，结论就一条：**长周期付款前确认当期续费规则，别默认续费价等于首购价。**

还有个容易漏看的差异：新加坡 DC2 机房分配的 IPv6 是 /112 地址段，东京和香港 DC1 是 /64，对 IPv6 有刚需的人下单前要看清机房。
